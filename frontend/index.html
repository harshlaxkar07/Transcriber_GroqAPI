Stages

Split
The recording is cut into fixed-length WAV chunks so each request stays well inside the model's limits.
Transcribe
Each chunk is sent to the Groq speech-to-text model, which returns text plus the detected language and duration.
Merge
Chunk transcripts are joined in order and written to a single text file named after the recording.
Extract
The merged transcript is passed to the language model to pull out the structured details you care about.
